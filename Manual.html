О системе

Visual Pipeline — это программный комплекс для автоматизации учета маркировки на металлопродукции.
Он использует компьютерное зрение для распознавания ID на торцах труб и позволяет экспортировать данные в CSV формате.

Как настроить сканирование

  • Слайдер Confidence: Установите на 40-50% для оптимального результата.
  • Загрузка: Нажмите на зону "Входные файлы" и выберите фото торцов труб.

Экспорт данных

После завершения анализа нажмите "EXPORT CSV". Файл будет содержать все ID и точность распознавания.
